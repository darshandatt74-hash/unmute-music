# 🎵 Unmute Music

Unmute Music is a modern music streaming web application built for listening, managing, and exploring songs with a clean dark UI.

---

## 🚀 Features

- 🎧 Music Streaming
- 🔍 Search Songs
- ❤️ Like Songs
- 📂 Playlist Management
- 👤 User Login & Registration
- 🎵 Music Player Controls
- 📱 Responsive Design
- 🌙 Modern Dark Theme

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
